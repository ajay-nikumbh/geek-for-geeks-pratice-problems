# GeeksforGeeks Practice Problems

Structured collection of GeeksforGeeks Practice problems, organized topic-wise for systematic DSA preparation.

Source: [GfG Practice — Explore](https://www.geeksforgeeks.org/explore?sortBy=submissions)

## Structure

```
01. <Topic>/
  01. Basics/
    01. <Problem Name>/
      README.md
  02. Easy/
  03. Medium/
  04. Hard/
02. <Topic>/
...
```

- Topics numbered in GfG's submissions-sorted order.
- Each topic split into difficulty subfolders: Basics, Easy, Medium, Hard.
- Each problem folder numbered by submission count (descending) within its difficulty, and holds a `README.md` placeholder for the article/solution.
- `_manifest.json` — full flat index (topic, difficulty, name, GfG URL, folder path) for all problems.
